## 🔧 Essential Commands

### Test Execution
```bash
# Navigate to app directory
cd e:\GitHub\codai-project\apps\[APP_NAME]

# Install dependencies if needed
pnpm install

# Run tests with detailed output
pnpm test run --reporter=verbose

# Run specific test file
pnpm test run path/to/test.file.ts

# Run tests in watch mode for development
pnpm test run --watch
```

### File Operations
```bash
# Search for test files
Get-ChildItem -Path . -Recurse -Filter "*.test.*" | Select-Object FullName

# Find empty or placeholder test files
findstr /M "// TODO\|// PLACEHOLDER\|// Full test suite implementation" **/*.test.ts

# Check test completion status
pnpm test run --silent | findstr "passed\|failed\|Test Files"
```
