# RomAI Project Structure

This document describes the organized structure of the RomAI project after the code cleanup initiative.

## Directory Organization

### 📁 `/apps/romai/`
**Main RomAI Application**
- Core AI implementation
- ML models and serving infrastructure
- Neural networks and reasoning engines

### 🧪 `/tests/`
**Test Suite**
- Validation tests for RomAI capabilities
- Benchmark tests and performance validation  
- ARC AGI evaluation tests
- Production readiness assessments

### 🔧 `/scripts/`
**Utility Scripts**
- Training and deployment automation
- Data generation and processing
- Model training pipelines
- Development and maintenance tools

### 🛠️ `/tools/`
**Advanced Tools**
- Consciousness integration system
- Neural orchestration tools
- Pattern analysis utilities
- Reality grounding systems

### 📊 `/reports/`
**Generated Reports**
- Benchmark validation results
- Performance test reports
- Continuous learning metrics
- Scientific research outputs

### 🐛 `/debug/`
**Debug Utilities**
- Analysis and debugging scripts
- Pattern investigation tools
- System validation utilities

## File Naming Conventions

### ✅ Good Naming Patterns
- `romai_validation.py` → Clear, descriptive
- `multi_domain_validation.py` → Functional naming
- `consciousness_integration.py` → Intent-based naming

### ❌ Avoid These Patterns
- `final_multi_domain_excellence_validation.py` → Too verbose
- `scientific_research_engine_test_report_2025-08-24_16-35-36.json` → Excessive timestamps
- `check_arc_008.py` → Generic naming

## Organization Benefits

1. **🎯 Clear Purpose**: Each directory has a specific function
2. **🔍 Easy Navigation**: Related files are grouped together
3. **📝 Consistent Naming**: Shorter, more descriptive names
4. **🧹 Clean Root**: No scattered files in project root
5. **📊 Report Management**: All generated reports in one location

## Development Workflow

1. **New Tests** → Add to `/tests/` directory
2. **Utility Scripts** → Add to `/scripts/` directory  
3. **Advanced Tools** → Add to `/tools/` directory
4. **Generated Reports** → Automatically saved to `/reports/`
5. **Debug Code** → Use `/debug/` for analysis scripts

## File Management

- **Short Names**: Keep filenames under 40 characters
- **Descriptive**: Name should indicate purpose
- **Consistent**: Follow snake_case convention
- **Organized**: Place in appropriate directory

This organization follows software engineering best practices and makes the RomAI project much more maintainable and professional.
