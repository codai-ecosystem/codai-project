## 📊 Service Architecture Patterns

### Technology Stack Standardization

- **Frontend**: Next.js 15 + React 19 + TypeScript 5.8
- **Styling**: Tailwind CSS + Radix UI + Framer Motion
- **State Management**: Zustand (lightweight) + Redux (complex workflows)
- **Testing**: Vitest + React Testing Library + Playwright E2E
- **Database**: PostgreSQL (primary) + Redis (caching) + specialized stores
- **Authentication**: NextAuth.js + OAuth 2.0 + JWT tokens
- **Deployment**: Docker + Kubernetes + Azure infrastructure

### Port Allocation Strategy

- **Core Services**: 4000-4020 (Gateway, ID, MemorAI, Hub, Admin, etc.)
- **Business Services**: 4021-4040 (CODAI, BancAI, CumparAI, etc.)
- **Specialized AI**: 4041-4060 (ConversAI, StudiAI, TalentAI, etc.)
- **Industry Specific**: 4061-4080 (LegalizAI, AcasAI, SunAI, etc.)
- **Development Tools**: 3000-3020 (Local development ports)

### Integration Patterns

1. **Gateway-Routed**: All external access through Gateway (Port 4000)
2. **Service-to-Service**: Direct internal communication with service discovery
3. **Event-Driven**: Asynchronous communication via message queues
4. **Shared Memory**: MemorAI as central memory provider
5. **Unified Auth**: ID Service as authentication provider
