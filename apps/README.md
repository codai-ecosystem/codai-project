## 🚀 Getting Started

### Prerequisites
- Node.js 20+ LTS
- pnpm 8.15.0+

### Development
```bash
# Install dependencies
pnpm install

# Start core application
cd apps/codai && pnpm dev

# Start with specific port
cd apps/memorai && pnpm dev --port 4031
```
