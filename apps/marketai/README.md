# MARKETAI

## Overview
marketai application - part of the CODAI ecosystem.

## Quick Start
```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Run tests
pnpm test
```

## Features
- Modern Next.js 15 architecture
- TailwindCSS 3 styling
- Comprehensive test coverage
- TypeScript support
