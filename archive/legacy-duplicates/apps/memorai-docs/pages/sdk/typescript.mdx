# TypeScript SDK

The MemorAI TypeScript SDK provides a fully-typed, intuitive interface for integrating MemorAI into your Node.js and browser applications.

## Installation

```bash
npm install @memorai/sdk
# or
pnpm add @memorai/sdk
# or
yarn add @memorai/sdk
```

## Quick Start

```typescript
import { MemorAIClient } from '@memorai/sdk';

const client = new MemorAIClient({
  apiKey: 'your-api-key-here',
  baseURL: 'https://api.memorai.ro' // Optional
});

// Create a memory
const memory = await client.memories.create({
  content: 'My first memory',
  metadata: { type: 'note' }
});

console.log(`Created memory: ${memory.id}`);
```

## Configuration

### Basic Configuration

```typescript
const client = new MemorAIClient({
  apiKey: 'your-api-key',           // Required
  baseURL: 'https://api.memorai.ro', // Optional, defaults to production
  timeout: 30000,                   // Optional, request timeout in ms
  retries: 3,                       // Optional, number of retries
  userAgent: 'MyApp/1.0.0'         // Optional, custom user agent
});
```

### Advanced Configuration

```typescript
const client = new MemorAIClient({
  apiKey: process.env.MEMORAI_API_KEY!,
  baseURL: process.env.MEMORAI_BASE_URL,
  
  // HTTP client options
  timeout: 30000,
  retries: 3,
  retryDelay: 1000,
  
  // Authentication options
  authType: 'bearer', // or 'api-key'
  
  // Request options
  headers: {
    'X-Custom-Header': 'value'
  },
  
  // Debugging
  debug: process.env.NODE_ENV === 'development',
  
  // Rate limiting
  rateLimitRetry: true,
  maxRateLimitRetries: 5
});
```

## Memory Management

### Creating Memories

```typescript
// Basic memory creation
const memory = await client.memories.create({
  content: 'Important meeting notes from today',
  metadata: {
    type: 'meeting',
    tags: ['work', 'important'],
    date: '2024-01-15',
    participants: ['alice@company.com', 'bob@company.com']
  }
});

// Memory with vector embedding
const vectorMemory = await client.memories.create({
  content: 'Technical documentation about API design',
  vector: [0.1, 0.2, 0.3, /* ... 1536 dimensions */],
  metadata: {
    type: 'documentation',
    category: 'api-design'
  }
});

// Memory in a specific collection
const collectionMemory = await client.memories.create({
  content: 'Project milestone completed',
  collectionId: 'col_abc123',
  metadata: { milestone: 'Phase 1' }
});
```

### Retrieving Memories

```typescript
// Get a specific memory
const memory = await client.memories.get('mem_abc123');

// List memories with pagination
const response = await client.memories.list({
  limit: 50,
  cursor: 'eyJpZCI6IjEyMyJ9', // Optional, for pagination
  filter: {
    tags: ['important', 'work'],
    type: 'meeting',
    dateFrom: '2024-01-01',
    dateTo: '2024-01-31'
  },
  sort: {
    field: 'createdAt',
    order: 'desc'
  }
});

console.log(`Found ${response.data.length} memories`);
console.log(`Total: ${response.meta.pagination.total}`);
```

### Updating Memories

```typescript
// Update memory content
const updated = await client.memories.update('mem_abc123', {
  content: 'Updated meeting notes with action items',
  metadata: {
    status: 'completed',
```

### Deleting Memories

```typescript
// Delete a single memory
await client.memories.delete('mem_abc123');

// Bulk delete with filter
const deleted = await client.memories.bulkDelete({
  filter: {
    tags: ['temporary'],
    type: 'draft'
  }
```

## Real-time Features

### WebSocket Connection

```typescript
// Connect to real-time updates
const realtime = client.realtime.connect({
  autoReconnect: true,
  heartbeatInterval: 30000
});

// Listen for events
realtime.on('memory.created', (memory) => {
  console.log('New memory created:', memory.id);
});

realtime.on('memory.updated', (memory) => {
  console.log('Memory updated:', memory.id);
});

realtime.on('memory.deleted', (memoryId) => {
  console.log('Memory deleted:', memoryId);
});

// Subscribe to specific collections
realtime.subscribe('collection.col_abc123');

// Unsubscribe from events
realtime.unsubscribe('collection.col_abc123');

// Close connection
realtime.disconnect();
```

### Real-time Search

```typescript
// Live search with real-time updates
const liveSearch = client.search.live({
  query: 'project updates',
  onResults: (results) => {
    console.log('Search results updated:', results.length);
  },
  onError: (error) => {
    console.error('Search error:', error);
  }
});

// Update search query
liveSearch.updateQuery('new project updates');

// Stop live search
liveSearch.stop();
```

## Error Handling

### Basic Error Handling

```typescript
try {
  const memory = await client.memories.create({
    content: 'Test memory'
  });
} catch (error) {
  if (error instanceof MemorAIError) {
    console.error('MemorAI Error:', error.code, error.message);
    console.error('Request ID:', error.requestId);
  } else {
    console.error('Unexpected error:', error);
  }
}
```

### Specific Error Types

```typescript
import { 
  MemorAIError, 
  AuthenticationError, 
  RateLimitError, 
  ValidationError 
} from '@memorai/sdk';

try {
  await client.memories.create({ content: '' });
} catch (error) {
  if (error instanceof AuthenticationError) {
    // Handle auth errors
    console.error('Authentication failed:', error.message);
  } else if (error instanceof RateLimitError) {
    // Handle rate limiting
    console.error('Rate limited. Retry after:', error.retryAfter);
  } else if (error instanceof ValidationError) {
    // Handle validation errors
    console.error('Validation failed:', error.details);
  }
}
```

## Best Practices

### 1. Configuration Management

```typescript
// Use environment-based configuration
const config: MemorAIConfig = {
  apiKey: process.env.MEMORAI_API_KEY!,
  baseURL: process.env.MEMORAI_BASE_URL || 'https://api.memorai.ro',
  timeout: parseInt(process.env.MEMORAI_TIMEOUT || '30000'),
  debug: process.env.NODE_ENV === 'development'
};

const client = new MemorAIClient(config);
```

### 2. Error Handling & Retry Logic

```typescript
async function createMemoryWithRetry(data: CreateMemoryRequest, maxRetries = 3) {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      return await client.memories.create(data);
    } catch (error) {
      if (error instanceof RateLimitError && attempt < maxRetries) {
        await new Promise(resolve => setTimeout(resolve, error.retryAfter * 1000));
        continue;
      }
      throw error;
    }
  }
}
```

### 3. Efficient Pagination

```typescript
async function getAllMemories(filter?: MemoryFilter) {
  const memories: Memory[] = [];
  let cursor: string | undefined;
  
  do {
    const response = await client.memories.list({
      limit: 100,
      cursor,
      filter
    });
    
    memories.push(...response.data);
    cursor = response.meta.pagination.nextCursor;
  } while (cursor);
  
  return memories;
}
```

### 4. Resource Cleanup

```typescript
class MemorAIService {
  private client: MemorAIClient;
  private realtimeConnection?: RealtimeConnection;
  
  constructor(config: MemorAIConfig) {
    this.client = new MemorAIClient(config);
  }
  
  async connect() {
    this.realtimeConnection = this.client.realtime.connect();
  }
  
  async disconnect() {
    if (this.realtimeConnection) {
      await this.realtimeConnection.disconnect();
      this.realtimeConnection = undefined;
    }
  }
}
```
