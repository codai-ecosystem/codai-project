# Development Tools & Scripts

This directory contains development utilities, scripts, and tools for the CODAI ecosystem.

## Structure

### `/scripts/`

Development and automation scripts:

- Build scripts
- Deployment automation
- Database scripts
- Utility scripts

### `/tools/`

Development tools and utilities:

- Custom development tools
- Build tools
- Analysis tools
- Testing utilities

## Usage

These tools and scripts support the development workflow across all CODAI services and applications.

### Scripts

Navigate to `scripts/` to find automation and utility scripts for common development tasks.

### Tools

Navigate to `tools/` to find custom development tools and utilities.

## Contributing

When adding new development tools or scripts:

1. Place in appropriate subdirectory
2. Update this README with description
3. Ensure proper documentation in the file
4. Test thoroughly before committing
