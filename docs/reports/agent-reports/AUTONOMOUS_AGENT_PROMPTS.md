## 🔄 AUTONOMOUS COORDINATION PROTOCOL

### Memory-Based Task Detection
All agents automatically:

1. **Check Ecosystem State**:
   ```javascript
   mcp_memoraimcpser_recall("agent_ID", "ecosystem_status priorities blockers")
   ```

2. **Assess Territory Status**:
   ```javascript
   mcp_memoraimcpser_recall("agent_ID", "my_apps app_status running_ports health_metrics")
   ```

3. **Identify Priority Tasks**:
   ```javascript
   mcp_memoraimcpser_recall("agent_ID", "high_priority urgent_tasks dependencies")
   ```

4. **Execute Next Task**:
   - Navigate to appropriate app directory
   - Run deployment/fix/optimization commands
   - Report progress to memory

5. **Update Status**:
   ```javascript
   mcp_memoraimcpser_remember("agent_ID", "Task completed: [description]", 
     {entityType: "task_completion", progress: "X%", nextTask: "Y"})
   ```

### Cross-Agent Coordination
- Agents automatically detect when they need help from other agents
- Requests for assistance are stored in memory with priority levels
- Available agents automatically offer help when their territory is complete
- Conflict resolution through memory-based negotiation

### Continuous Improvement
- Agents learn from successful task patterns stored in memory
- Performance metrics guide automatic optimization decisions
- Failed tasks trigger automatic alternative approach selection
- Success patterns are shared across similar agent types

To activate any agent, simply run:

```
You are Agent #X (Specialization) in the CODAI Multi-Agent Orchestration System.
```

The agent will automatically:
1. Check memory for current ecosystem state
2. Assess their territory status
3. Identify the highest priority task

**No manual task assignment needed!** Each agent autonomously determines and executes their optimal next action based on the current ecosystem state and their specialized role.
