## 🛠️ Test Execution Commands

### **Execute All Tests**
```bash
npx playwright test tests/e2e/ --reporter=list
```

### **Execute Specific Service Tests**
```bash
# CODAI Service
npx playwright test tests/e2e/codai-detailed-testing.spec.ts

# Admin Service  
npx playwright test tests/e2e/admin-comprehensive-testing.spec.ts

# Hub Service
npx playwright test tests/e2e/hub-comprehensive-testing.spec.ts

# ID Service
npx playwright test tests/e2e/id-comprehensive-testing.spec.ts

# BancAI Service
npx playwright test tests/e2e/bancai-comprehensive-testing.spec.ts

# Gateway Service
npx playwright test tests/e2e/gateway-comprehensive-testing.spec.ts
```

### **Execute with UI Debug Mode**
```bash
npx playwright test tests/e2e/ --ui
```

### **Execute with Specific Browser**
```bash
npx playwright test tests/e2e/ --project=chromium
npx playwright test tests/e2e/ --project=firefox
npx playwright test tests/e2e/ --project=webkit
```

### **Execute with Maximum Failures Limit**
```bash
npx playwright test tests/e2e/ --max-failures=10
```
