## 🚀 New Capabilities (v9.0.0)

### AI-Powered Relationship Intelligence

- **Automatic Detection**: AI analyzes memory content to detect relationships
- **8 Relationship Types**: related, explains, references, contradicts, builds_on, implements, exemplifies, depends_on
- **Configurable Strength**: Relationship strength scoring (0-1)
- **Context Awareness**: Optional context for relationship meaning

### Knowledge Graph Construction

- **Graph Building**: Automatic knowledge graph construction from memories
- **Node Analysis**: Memory nodes with centrality scoring
- **Edge Networks**: Relationship edges with strength weighting
- **Community Detection**: Automatic clustering of related memories
- **Graph Traversal**: Multi-depth exploration with configurable radius

### Advanced Search Intelligence

- **Multi-Dimensional Scoring**: Semantic, temporal, contextual, and usage-based relevance
- **Query Expansion**: AI-powered query enhancement and synonym detection
- **Fuzzy Matching**: Intelligent handling of typos and variations
- **Result Clustering**: Automatic grouping of related search results
- **Relationship-Aware Ranking**: Search results enhanced by relationship data

## 🔧 New MCP Tools

### 1. `mcp_memoraimcp_link_memories`

Create explicit relationships between memories with custom types and strength.

### 2. `mcp_memoraimcp_get_relationships`

Retrieve relationships for a memory with configurable depth and filtering.

### 3. `mcp_memoraimcp_explore_graph`

Navigate knowledge graphs from any starting point with radius control.
