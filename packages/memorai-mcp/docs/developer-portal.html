Quick Start Guide

Get up and running with MemorAI in minutes

1

Install SDK

Install the MemorAI SDK using npm or yarn

2

Configure

Set up your API credentials and connection settings

3

Initialize

Create your MemorAI SDK instance and start building

4

Build

Use memory operations to enhance your application

# Install the MemorAI SDK
npm install @memorai/sdk

# Import and initialize
import MemorAISDK from '@memorai/sdk';

const sdk = new MemorAISDK({
  baseURL: 'http://localhost:4950',
  apiKey: 'your-api-key'
});

// Store a memory
const memory = await sdk.remember({
  content: 'User prefers dark mode',
  agentId: 'user-agent-001',
  metadata: { importance: 7 }
});

// Recall memories
const results = await sdk.recall({
  query: 'user preferences',
  limit: 10
});

console.log('Found memories:', results);
