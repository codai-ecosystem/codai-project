Universal Quick Start

These steps apply to all framework integrations. Choose your specific framework guide for detailed examples.

1

Install the SDK

Add MemorAI SDK to your project dependencies

npm install @memorai/sdk # or yarn add @memorai/sdk # or pnpm add @memorai/sdk
2

Environment Setup

Configure your environment variables

# .env MEMORAI_BASE_URL=http://localhost:4950 MEMORAI_API_KEY=your-api-key-here MEMORAI_AGENT_ID=your-agent-id
3

Framework Integration

Import and use the framework-specific integration

// React import { useMemorAI } from '@memorai/react'; // Vue import { useMemorAI } from '@memorai/vue'; // Angular import { MemorAIService } from '@memorai/angular'; // Vanilla JS import MemorAISDK from '@memorai/sdk';
4

Start Building

Begin using memory operations in your application

// Store a memory const memory = await memorai.remember({ content: 'User preferences updated', agentId: 'user-001', metadata: { importance: 7 } }); // Recall memories const results = await memorai.recall({ query: 'user preferences', limit: 10 });

Integration Best Practices

Follow these guidelines for optimal performance and maintainability

Performance

  • • Use connection pooling for multiple requests
  • • Implement proper caching strategies
  • • Debounce frequent memory operations
  • • Use pagination for large result sets

Security

  • • Store API keys securely (environment variables)
  • • Validate all user inputs before storing
  • • Use HTTPS for all API communications
  • • Implement proper error handling

Code Quality

  • • Use TypeScript for better type safety
  • • Implement comprehensive error boundaries
  • • Write unit tests for memory operations
  • • Document your memory schema
