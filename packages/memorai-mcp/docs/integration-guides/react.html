Installation & Setup

Get started with MemorAI in your React application with these simple steps.

# Install the core SDK and React integration npm install @memorai/sdk @memorai/react # Or with yarn yarn add @memorai/sdk @memorai/react # Or with pnpm pnpm add @memorai/sdk @memorai/react
Prerequisites

This guide assumes you have a React application (v16.8+ with hooks support) and a running MemorAI MCP server.

Environment Configuration

Create a .env file in your project root:

# .env REACT_APP_MEMORAI_BASE_URL=http://localhost:4950 REACT_APP_MEMORAI_API_KEY=your-api-key-here REACT_APP_MEMORAI_AGENT_ID=your-agent-id
Security Note

Never expose sensitive API keys in client-side code. Use environment variables with the REACT_APP_ prefix for public configuration only.

React Hooks Overview

MemorAI provides three main React hooks for different use cases.

useMemorAI
Primary hook for SDK management, memory operations, and connection state.
useMemorySubscription
Real-time memory updates via WebSocket connections with automatic reconnection.
useMemoryAnalytics
Analytics dashboard data with caching and automatic refresh intervals.

useMemorAI Hook

The main hook for MemorAI integration with complete SDK lifecycle management.

Basic Usage

Best Practices

1. Connection Management
Always handle connection states gracefully and implement reconnection logic.

2. Performance Optimization
Use proper dependency arrays and memoization to prevent unnecessary re-renders.
