📦 Installation

Via NPM

npm install @memorai/sdk # Then import in your JS files import { MemorAISDK } from '@memorai/sdk';

Via CDN

<script src="https://unpkg.com/@memorai/sdk@latest/dist/memorai.min.js"></script> <script> const { MemorAISDK } = window.MemorAI; </script>

⚡ Quick Start

// Initialize MemorAI SDK const memorai = new MemorAISDK({ baseURL: 'http://localhost:4950', apiKey: 'your-api-key-here', agentId: 'vanilla-js-app', enableWebSocket: true }); // Store a memory async function storeMemory() { try { const memory = await memorai.remember({ content: 'User clicked the subscribe button', agentId: 'vanilla-js-app', metadata: { importance: 6, tags: ['user-action', 'conversion'], timestamp: new Date().toISOString() } }); console.log('Memory stored:', memory); } catch (error) { console.error('Failed to store memory:', error); } } // Search memories async function searchMemories(query) { try { const results = await memorai.recall({ query: query, agentId: 'vanilla-js-app', limit: 10 }); console.log('Search results:', results); return results; } catch (error) { console.error('Search failed:', error); return []; } }

✨ Key Features

⚠️ Security Note

Never expose API keys in client-side code in production. Use environment variables or secure token exchange for production deployments.
